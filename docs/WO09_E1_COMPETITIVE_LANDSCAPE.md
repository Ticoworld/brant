Evidence labels matter. VERIFIED SOURCE means the indicated files were read at a pinned commit, not that we independently audited or executed those contracts. Website design/deployment statements are publisher claims. No external contracts were transacted with, no security tests were run against public systems, and no customer-demand inference is drawn from names, stars or grant votes.
