# Local browser order journey

**VERIFIED:** On the disposable CKB 0.210.0 node, two separate test-only CCC identities signed and published an order, discovered it through the local listing directory, and committed a fill and seller cancellation. The seller's entitlement was 6 both before and after cancellation; its revision advanced from 1 to 2. An intentionally constructed replay of the canceled signed order was rejected by the native custody script with VM error 38. A subsequent curve buy committed after the custody-only transitions. Raw transactions, rejection and screenshots: `apps/trade-testnet/evidence/v2-order-browser-1794492791626/`; corresponding bootstrap: `evidence/native-1794492718815/`.

Fill `0x0c5ac62e97e0fde1c550fe61560087c99082a8970736af056336751ae893b28b` (estimated 0x3bed05 cycles), cancel `0x22c5ba50b29e6cae4dc2f48ec653bf8c2b937edcd524e726e8119d4c8dd8b2cc` (0x1f6177), and post-order curve buy `0x0f96edbd241939b04b1e82cd0e94073d6ab0f4bf45cd8b1c4c2871dd12b23453` (0x22307a) each paid 100,000 shannons. The fill paid the signed 10,000,000,000-shannon minimum.

The order directory is local to the application host, requires fixture mode, and stores signed public orders. Listings may be stale; preparing a fill reconstructs canonical custody history and rechecks the revision. Orders do not have on-chain expiry and are not automatically matched. An external wallet and public order relay remain **UNVERIFIED**. The test injects public disposable fixture keys only into the isolated browser; never use them on Pudge.

Start a fresh node with the instructions in `BROWSER_BOOTSTRAP.md`. Build both proof binaries and the existing recovery verifier with `cargo build --release --locked --offline --manifest-path` pointing respectively at `browser-proof/Cargo.toml`, `smt-tools/Cargo.toml` and `recovery/Cargo.toml` under this directory. From `apps/trade-testnet` on Windows, set `V2_LOCAL_BOOTSTRAP` to the new bootstrap JSON, `ROVEKO_PROOF_BINARY` and `ROVEKO_SMT_BINARY` to their Windows release executables, and `TRADE_NATIVE_ROOT` to the pinned native tooling directory, then run `node --experimental-strip-types tests/v2-order-browser.mts`. The test starts a fixture-only Next server on port 3101 and uses localhost CKB RPC on port 19224. Stop the disposable node as described in `BROWSER_BOOTSTRAP.md`.
