# Revision 04 — owner screenshot direction

The owner's supplied screenshots guide this revision: compact application navigation, subdued surfaces, colour limited to actions/state, functional tabs instead of repeated headings, and a focused input-to-receipt workflow. Jupiter/Uniswap inform the default action surface; Hyperliquid/Orca inform the separate compact positions/market lists. No chart, order book, executable quote, volume or liquidity is fabricated.

Trade is now the default view. Selecting a position opens its action panel. Claim selection, amount, net receipt, fees and transaction review stay together. The green wash, large inventory tile and repeated cell decorations are removed. Necessary financial conditions remain in review/details. The empty state asks for a known market; unknown holdings/receipts are not displayed as real balances.

The controller, transaction builder, approval guards, configured covenant and public manifests remain unchanged. Wallet signing stays in the user's wallet under existing approval gates. Local browser fixtures are labelled, never external-wallet/Pudge acceptance. Source/build/browser and private-native evidence are indexed in result-summary.json. Previous designs and failed/historical evidence remain preserved in Git and earlier revision directories.
