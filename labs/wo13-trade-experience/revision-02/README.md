# WO13 visual revision 02

4 November 2026. Owner rejected the first design as wordy and generic. This revision replaces that visual direction; the earlier screenshots and evidence remain preserved.

Read-only, real browser inspection: Hyperliquid, Uniswap, Jupiter and Polymarket (`references.json` and reference screenshots). Questions used: does the screen help choose an action, why show three forms at once, why ask for a claim index already present in a row, and which explanation is only needed at review time?

Changes: flat navigation; compact tables; one selected-position action panel; no hero, marketing heading, large percentage graphic, stacked instructional cards or default status lecture. Exact financial terms, identities and diagnostics remain available in disclosures and transaction review. No prices, charts, market depth or activity were invented. Fixed backing, contract, builder, wallet policy and approval gates are unchanged.

The revised browser suite checks responsive layouts, action tabs, exact 0.099 CKB net preview for a 0.1 CKB gross redemption at the qualified fee, offer file exchange, review/cancellation, fail-closed states and accessibility smoke tests. Populated screenshots are labelled presentation fixtures, not wallet/Pudge evidence. Results are indexed in `result-summary.json`.

The native browser-builder regression uses disposable private-chain assets and Node-only fixture signing. It does not qualify an external wallet. Public signing and deployment remain disabled. The Windows handoff is unchanged except for the new visible labels and Sell/Import tabs.
