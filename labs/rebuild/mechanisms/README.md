# Isolated reconstructed mechanisms

Private disposable chains only. `python3 src/bootstrap.py`, `python3 src/build.py`, then `node src/compact-run.cjs`. Native dependencies are pinned in ../native/package-lock.json. CKB 0.210.0 bootstrap checks official archive SHA256; Zig 0.14.1 builds the compact C script. Set ZIG_BIN or CKB_BIN for preinstalled matching tools. TCP 19224/19225 must be free. Each run records fresh raw RPC, signed transactions, deployed code hashes and actual minimal code-cell capacity. `node src/verify.cjs evidence/<run>` cross-checks CCC, SDK and node responses.

C primitive: a funded native CKB bid stores the Blake2b hash of a 120-byte intent: owner lock hash, recipient lock hash, xUDT type hash, price numerator/denominator and minimum partial match. Funding preserves the preimage in a signed transaction witness; another process/node query can recover it without solver memory. Match consumes CKB into exact-recipient xUDT payouts and optional same-commitment CKB successors. Obligations aggregate by recipient+asset, rather than crediting a shared payout twice. Owner recovery requires a real owner-lock input, whose normal signature the node verifies. This is not authenticated intent-policy signing for arbitrary discovered orders.

One input per unique commitment, bid-only direction, MAX=2048 and quadratic local comparisons are explicit limits. No matching engine, passive upper expiry or universal uniqueness is claimed. It is a new functional reconstruction, not original missing C file recovery. C/A2 hybrid: CKB from compact bid goes into an authentic A2 ask successor while A2 tokens go directly to compact recipient in one transaction; A2 owner subsequently recovers its tracked successor. LO-01 is not fixed or adversarially reproduced by this composition test.

Rust variants: `python3 src/build-rust.py` installs pinned Rust1.74.0 in ignored local tools/, uses locked ckb-std0.15.3 and Zig0.14.1 glue, and builds source A2, 2-MiB A2 and the gate adapter. `node src/gate-run.cjs` runs a separate chain and genuine measured group cancellation. Published binary hashes are not altered. The source-built baseline is behaviorally tested, not claimed byte-identical to published A2. Compiler acquisition/target failures and fixed signing-mutant mistakes are documented in the revocation report.

Artifact separation: source rebuilds write `build/rebuilt/`, preserving previously deployed `build/` binaries. Use `MECHANISM_BUILD="$PWD/build/rebuilt" node src/gate-run.cjs` or `BATCH_SIZES=1536 MECHANISM_BUILD="$PWD/build/rebuilt" node src/batch-run.cjs` to execute rebuilt artifacts. Rust source paths are explicitly remapped. `node src/verify-source.cjs` checks all recorded source/tool-layout/build hashes. Same tool versions alone do not establish byte identity across source paths; measured deployed hashes are authoritative for each run. Large event histories are losslessly gzip-compressed; verifier reads either representation.
