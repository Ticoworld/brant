This application adapts selected presentation structures from raydium-io/raydium-ui-v3-public, pinned at commit 045a2a942711440b85e091ac313378a1e534f102.

Adapted areas include the responsive market-list hierarchy, swap-style amount input and information board, chart workspace, and portfolio overview composition. These adaptations replace Chakra primitives with React and Tailwind CSS utilities and are branded for Roveko.
